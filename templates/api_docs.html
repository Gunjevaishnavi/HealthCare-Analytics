REST API Endpoints Reference
HTTP Method Endpoint Path Description Authentication
GET /api/v1/patients Lists synthetic patients with optional filters (age_band, gender, chronic, limit, offset). API Key
POST /api/v1/patients Registers a new synthetic patient record. API Key
GET /api/v1/patients/{patient_id} Retrieves detailed patient profile, complete visit history, measurements, and active indicators. API Key
GET /api/v1/visits Lists clinical visits with department and admission type filters. API Key
POST /api/v1/visits Records a new patient visit/encounter. API Key
GET /api/v1/measurements Queries health measurements with validation status filtering. API Key
POST /api/v1/measurements Submits a new health measurement; automatically executes range validation and updates patient indicators. API Key
POST /api/v1/measurements/validate Validates arbitrary measurement values against documented physiological assumptions without saving. Public
GET /api/v1/indicators Returns computed risk indicators with rule documentation and limitations statement. API Key
GET /api/v1/indicators/rules Retrieves documented definitions, cutoffs, and educational rationale for all indicator rules. Public
POST /api/v1/indicators/evaluate/{patient_id} Re-evaluates transparent rules on latest patient measurements and updates stored flags. API Key
GET /api/v1/analytics/operational-summary Delivers full operational report (demographics, department throughput, NumPy summaries). API Key
